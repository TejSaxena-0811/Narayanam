# Narayanam

Narayanam is a full-stack web application designed to provide a structured and user-friendly platform for managing and interacting with content. It focuses on delivering a seamless user experience with secure authentication, dynamic data handling, and scalable architecture.

## Features

- Create, read, update, and delete core data entities
- Structured routing and modular backend design
- Form validation and error handling
- Flash messaging for user feedback
- Secure session management
- Clean and responsive UI using templating

---

## Tech Stack

### Frontend
- EJS (Embedded JavaScript Templates)
- CSS and static assets

### Backend
- Node.js
- Express.js

### Database
- MongoDB with Mongoose

### Libraries and Tools
- Joi (data validation)
- Connect-Flash (notifications)
- Express-Session and Connect-Mongo (session storage)
- Method-Override


## Run Locally
- cd frontend ---> npm run dev
- cd backend ---> nodemon server.js
